## Software implementation

All source code used to generate the results and figures in the paper are contained in this repository. The code is written in Python 3.11, and is organised in the following folders:

- The folder `DataGenerationROBIN` contains the code used to generate the synthetic dataset using the [ROBIN (Rail mOBIlity simulatioN)](https://github.com/JoseAngelMartinB/robin) python package. 

    The dataset is generated by simulating the demand for a set of train services in a competitive rail market, and the corresponding revenue for each service given a set of prices. The dataset is used to train the machine learning models and to evaluate the performance of the optimization with constraint learning models defined in this paper. In particular, the Spanish railway corridor Madrid-Barcelona (MAD-BCN) is used as a case study, and the prices of the train services were obtained using scraping techniques from the operators' websites, and later they were perturbed to generate a set of different price scenarios. The configuration files used in the ROBIN simulator to generate the dataset and the final dataset are stored in the `DataGenerationROBIN/data` folder. In particular, the `DataGenerationROBIN/data/aggregated` folder contains the final dataset used in the Constraint Learning models.

- The `ConstraintLearning` folder contains the code necessary for training the machine learning models and executing the optimization with constraint learning models defined in this paper.

    The folder `ConstraintLearning/preprocesed_data` contains the preprocessed version of the dataset generated in the `DataGenerationROBIN` folder, which is used to train the machine learning models. These models are stored in the `ConstraintLearning/saved_models` folder, and they are later used to define the constraints in the optimization models. The optimization models are defined in the `ConstraintLearning/Model_X` folders, where `X` is the number of the model. Finally, the folder `ConstraintLearning/validation_data` contains the metrics obtained when evaluating the performance of the optimized prices using the ROBIN simulator.

- The root folder contains the environment file with the Anaconda/Mamba dependencies needed to execute the code.


## Getting the code

You can download a copy of all the files in this repository by cloning the
[git](https://git-scm.com/) repository:

    git clone https://github.com/JoseAngelMartinB/DCL-train-market.git

or [download a zip archive](https://github.com/JoseAngelMartinB/DCL-train-market/archive/master.zip).


## Dependencies

You will need a working Python environment to run the code.
The recommended way to set up your environment is through the
[Anaconda Python distribution](https://www.anaconda.com/download/) which
provides the `conda` package manager.
Anaconda can be installed in your user directory and does not interfere with
the system Python installation.
The required dependencies are specified in the file `environment.yml`.

We use `conda` virtual environments to manage the project dependencies in
isolation.
Thus, you can install our dependencies without causing conflicts with your
setup (even with different Python versions).

Run the following command in the repository folder (where `environment.yml`
is located) to create a separate environment and install all required
dependencies in it:

    conda env create -f environment.yml

This will create a new conda environment named `dcl-trainmarket` with all the 
required dependencies installed.


## Reproducing the results

Before running any code you must activate the conda environment you just 
created, by running:

    conda activate dcl-trainmarket

This will enable the environment for your current terminal session.
Any subsequent commands will use software that is installed in the environment.

To execute the Jupyter notebooks you must first start the notebook server by 
going into the repository top level and running:

    jupyter notebook

This will start the server and open your default web browser to the Jupyter
interface. In the page, select the notebook that you wish to view/run.

The notebook is divided into cells (some have text while other have code).
Each cell can be executed using `Shift + Enter`.
Executing text cells does nothing and executing code cells runs the code
and produces it's output.
To execute the whole notebook, run all cells in order.

In the case of python scripts, you can run them from the command line using:

    python3 <script_name>.py

Alternatively, you can use the bash script `python_log.sh`, available in the 
`ConstraintLearning` folder, to run the scripts and save the output in a log
file for later analysis. For example, to run the script 
`validate_results_ROBIN.py`, you can run:

    cd ConstraintLearning
    ./python_log.sh validate_results_ROBIN.py


## Figures, tables and extra results not included in the paper

The figures and tables included in the paper are generated in the Jupyter notebooks,
and stored in the `figures/` and `latex_tables` subfolders, respectively, under
both the `DataGenerationROBIN` and `ConstraintLearning` folders.
Moreover, those folders also contain some extra figures and tables that are not 
included in the research paper, but are provided for completeness and 
reproducibility of the results.
